    Install Riffbolt

    iPhone or iPad

    Open Riffbolt in Safari. Tap Share (the square with an up arrow); open the … menu first if needed. Choose Add to Home Screen; if missing, find it under Edit Actions. Turn on Open as Web App if shown, then tap Add.

    Android

    Open Riffbolt in Chrome. Tap the ⋮ menu, then Add to home screen or Install app. Choose Install if offered and follow the prompts.

    Computer

    In Chrome or Edge, look for Install in the address bar or browser menu. On a Mac in Safari, choose File → Add to Dock.

    The app and saved points open offline. YouTube playback needs internet.

    Loop it. Nail it.

    By Ryan L. Melvin

    Set A and B at least half a second apart. Edit either time as minutes:seconds or seconds. Repeat uses YouTube seeks; buffering and short gaps can occur. Speed choices come from the video.

    Export your whole practice history. Import merges it with this browser’s history, keeping the most recently practiced version of each loop.

    Privacy & terms

    This browser saves your current loop, practice history, and YouTube consent. Clear saved browser data removes all three. There are no app accounts or analytics. Riffbolt is provided as-is, without a playback or timing guarantee.
